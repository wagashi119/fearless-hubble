# ココフォリア タイムラインビューア (CCFOLIA Timeline Viewer)

ココフォリア（CCFOLIA）からエクスポートしたJSONログを読み込んで、**動画編集ソフトのタイムラインのように時間軸で俯瞰・閲覧**できるWebアプリケーションです。

---

## 🔒 プライバシー・セキュリティについて

本ツールは**完全クライアントサイド（ブラウザ内完結）**で動作します。
読み込んだセッションログデータやマーカー情報が外部サーバーへ送信・保存されることは一切ありません。オフライン環境でも安心してご利用いただけます。

---

## 🌟 主な機能

### 1. 🎬 動画編集ソフト風・横軸タイムライン（シーケンサー）
- **時間軸ルーラー**: 上部に時刻・日付の目盛りが横方向に展開。赤色の再生ヘッド（シークバー針）で現在の位置を直感的に把握可能。
- **タイムグリッド線（1秒・1分・1時間）**:
  - 拡大率に合わせて、**1秒 / 5秒 / 1分 / 1時間** の単位を示すグリッド線がトラック全体を縦に貫通。
  - 発言の正確なタイミングや会話の間（沈黙）が一目瞭然。
- **トラック（レーン）構造**:
  - **マーカートラック**: 配置されたチャプター・しおり・ピンがリボン型クリップとして並び、ワンクリックでシーク。
  - **ダイス / 名場面トラック**: クリティカル（黄金エフェクト）やファンブル（赤エフェクト）、ダイス結果が目立つバッジクリップとして表示。
  - **主要キャラクター別トラック**: 主要キャラクターごとに独立したレーンが割り当てられ、発言のタイミングがクリップとして配置。
  - **その他・システムトラック**: HP/MP変動やシステムメッセージ用のレーン。
- **クリップ文字数の最適化**:
  - タイムラインを俯瞰しやすくするため、各クリップは **10文字以内** のコンパクトなバッジ形式で表示。
- **横方向のワイドズーム（拡大縮小）**:
  - スライダーや `[+]` `[-]` ボタンで **20% 〜 800%** まで滑らかにズームイン/ズームアウト。
  - 「画面幅にフィット」ボタンでセッション全体を一望。
- **日付フォーカス**: 複数日にわたるセッションでも、特定の日付を選択してその日のプレイ時間（数時間）を秒・分単位で拡大俯瞰可能。
- **自動再生（オートスクロール）**: 再生ボタンを押すと、セッションの流れを動画のように自動シーク再生。
- **インスペクター / プレビューモニター**: タイムライン上で選択したクリップの全文、ダイス結果、アイコン、マーカー編集を画面下部に常時大きく表示。

### 2. 📝 縦型チャットタイムライン表示
- じっくり会話ログを読み進めたいときに最適な縦スクロール表示。ヘッダーのボタンでいつでも横軸シーケンサーと相互切替可能。

### 3. 🔖 マーカー機能（しおり・ピン・チャプター）
- 任意の発言に「+」ボタンを押すだけでマーカー（タイトル・メモ・カテゴリ・ピンカラー・アイコン）を配置。
- 「自動検出」機能でログ内のチャプター名やクリティカル/ファンブルを一括マーカー化。
- ブラウザ（LocalStorage）への自動保存、JSON形式でのエクスポート＆インポートに対応。

### 4. 📊 セッション統計サマリー
- 総発言数、ダイスロール数、クリティカル/ファンブル確率、キャラクター別発言ランキングなどをグラフで可視化。

## 🚀 GitHub Pages への公開手順

本リポジトリには **GitHub Actions による自動ビルド＆デプロイワークフロー**（`.github/workflows/deploy.yml`）が含まれています。

1. 本リポジトリを GitHub にプッシュします。
2. GitHub のリポジトリページで **Settings** > **Pages** を開きます。
3. **Build and deployment** の **Source** を **`GitHub Actions`** に設定します。
4. `main`（または `master`）ブランチへのプッシュをトリガーに、自動的にビルドとデプロイが実行され、数分で公開URLが発行されます。

## 🛠 ローカル開発

```bash

npm install

# 開発サーバーの起動 (http://localhost:5173)
npm run dev

# プロダクションビルド
npm run build
```
